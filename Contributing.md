# Zasady współpracy
Cześć, dzięki za zainteresowanie projektem...

## Jak zacząć
Jeśli chcesz dołączyć do projektu stwórz **Issue** z odpowiednią etykietą lub skorzystaj z gotowego szablonu

## Branche
Jeśli chcesz stworzy nowy branch nazwij go według wzoru:
- `docs: opis`
- `fix: opis`

## Commity
Commity opisuj w trybie rozkazującym np. dodaj nowy plik

Dzięki za Twój wkład 😊
